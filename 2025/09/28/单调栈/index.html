单调栈

单调栈的经典问题

  • 0）当前位置的 左侧比当前位置的数字小，且距离最近的位置 在哪

  • 1）当前位置的 右侧比当前位置的数字小，且距离最近的位置 在哪

    或者：

  • 0）当前位置的 左侧比当前位置的数字大，且距离最近的位置 在哪

  • 1）当前位置的 右侧比当前位置的数字大，且距离最近的位置 在哪

单调栈操作的时间复杂度为O(n)

case 1:数组中没有重复元素

  • 将数组的元素依次入栈，并且栈中的元素满足：越靠近栈顶的元素越大
  • 如果当前元素比栈顶元素更大，则当前元素入栈。
  • 如果当前元素(cur)比栈顶元素小，则栈顶元素(top)出栈。此时可以更新结果：top右侧比当前位置的数字小，且距离最近的位置即为cur，而左侧比当前位置的数字小，且距离最近的位置即为栈中在top之下的元素

如图：cur为3，则7的右侧答案为3，左侧答案为6。6的右侧答案3，左侧答案为5。5的右侧答案为3，左侧答案为2。

case2:数组中有重复元素

  • 栈仍然保持严格的单调性，所以左侧答案一定是正确答案，但右侧答案可能出错，如此时下标0位置的2的右答案被记录为下标为4的2
  • 此时需要修正ansRight[i] = ansRight[ ansRight[i] ],即上图中ansRight[0] == ansRight[4] == ansRight[12]，选择从右向左修正可以避免多级索引

对重复元素的分析：

所以不用担心height[2]有一个错误的右侧，height[4]将进行答案的修正

给定一个整数数组 A，坡是元组 (i, j)，其中 i < j 且 A[i] <= A[j]。这样的坡的宽度为 j - i。

找出 A 中的坡的最大宽度，如果不存在，返回 0 。

示例 2：

提示：

  1. 2 <= A.length <= 50000

建立小压大的单调栈：

若nums[i] >= nums[stack.top()]则无需入栈，假设i与j位置构成了一个坡宽度为j-i，那么stack.top()和j位置一定也能形成坡(nums[j] > nums[i] > nums[stack.top()])，并且宽度更宽。

若遇到nums[i] < nums[stack.top()]则入栈，可能是最大宽度。

最后从后向前遍历，获得宽度。
